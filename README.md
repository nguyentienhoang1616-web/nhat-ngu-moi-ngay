# Nhật Ngữ Mỗi Ngày

App học tiếng Nhật cho người Việt, mở trên điện thoại hoặc máy tính, cài được vào màn hình chính, chạy không cần mạng.

- 8.034 từ vựng JLPT N5 → N1 (cách đọc, nghĩa tiếng Việt, câu ví dụ)
- 2.136 kanji Jōyō (nghĩa, Hán Việt, âm On/Kun, mẹo nhớ bằng hình)
- 28 tình huống kaiwa thực tế, 980 câu + 84 hội thoại (có romaji)
- Bảng chữ cái hiragana / katakana
- Thẻ ôn lặp lại ngắt quãng, trang tiến độ, 5 kiểu bài tập
